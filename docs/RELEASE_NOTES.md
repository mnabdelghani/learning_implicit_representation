# Supplementary research package (prepublication)

This package contains the standalone supplementary LaTeX/PDF, supporting derivations, additional examples, main-study numerical implementations and selected recorded traces, new paired contact-excitation study, reproducibility scripts and tests.

**Excluded:** The definitive 10-page paper's LaTeX and PDF, the alternative extended manuscript, and patches that could reconstruct the withheld manuscript.

The original full 100-run data archive is distributed separately; the checksum manifest identifies its exact contents. The active-flow example remains an unvalidated prototype. The ellipse material is archival only. The user has not yet selected an open-source license or assigned a DOI.
